# 🍔 Hamburguesas Milesha

### Aplicación de realidad aumentada para personalizar hamburguesas

Proyecto desarrollado con **Unity y Vuforia**, que permite a los usuarios crear su propia hamburguesa en realidad aumentada, seleccionando ingredientes y visualizando los cambios en un modelo 3D.

## ✨ Funcionalidades

- 🍔 Personalización de hamburguesas en 3D.
- 🥓 Agregar y eliminar ingredientes.
- 🧀 Selección de complementos.
- 💰 Cálculo automático del precio.
- 🛒 Resumen y confirmación del pedido.
- 📱 Visualización mediante realidad aumentada en Android.

## 🛠️ Tecnologías utilizadas

`Unity` · `Vuforia Engine` · `C#` · `Blender` · `Android`
